# Operon Skills

Platform-specific agent skills for working with Operon through the Operon CLI
and live Agent Runtime.

## Skills

| Skill | Description |
| --- | --- |
| [operon-tasks](./operon-tasks) | Create, find, update, transition, schedule, track, and organize Operon tasks through the live Runtime, with dictation-first daily workflows for Claude and Codex. |
| [operon-cli](./operon-cli) | Use the Operon CLI for complete command reference, typed mutations, sealed plan workflows, operational limits, diagnostics, and error recovery. |

Each skill family contains a `MANIFEST.md` and separate platform packages.
Platform packages are intended to be installed into the matching agent skill
directory rather than executed directly from this source tree.
