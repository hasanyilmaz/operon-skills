# Operon Skills

Platform-specific agent skills for working with Operon.

## Skills

- `operon-tasks` — Daily Operon task operations through the live Runtime.
- `operon-cli` — Complete Operon CLI reference and advanced workflows.

Each skill family contains a `MANIFEST.md` and separate platform packages.
Platform packages are intended to be installed into the matching agent skill
directory rather than executed directly from this source tree.
